## Free Test Key

The free test key lets you try the full v2 API without a card:

- 25 API calls in total, valid for 30 days from the moment you claim it
- Claimed once per account from the [dashboard](https://humandesignapi.nl/dashboard)
- Works on the v2 API only. Calling a v1 endpoint returns `403` with error code [`ACCESS_DENIED`](/api-reference/error-codes#authorization-errors)
- When all 25 API calls are used, the API returns `402` with [`TEST_KEY_EXHAUSTED`](/api-reference/error-codes#billing-errors)
- After 30 days, the API returns `402` with [`TEST_KEY_EXPIRED`](/api-reference/error-codes#billing-errors)
- Unused test calls end when you buy the Lifetime License or the Monthly plan

## API Calls

### Monthly Allocation

Your API calls reset every month: 3,000 on the Lifetime License, 10,000 on the Monthly plan.

### Rollover

On the Monthly plan, unused API calls roll over to the next month, up to a total balance of 20,000. Anything beyond that is lost at reset. The Lifetime License has no rollover.

**Example**: on the Monthly plan you use 7,000 API calls in March, leaving 3,000 unused. In April you start with 13,000 API calls (10,000 new + 3,000 rolled over). If you had 15,000 unused, you would start April with 20,000, the maximum balance.

### Extra Calls

Extra calls are **off by default**. When you turn them on:

- API calls beyond your monthly allocation keep working and are billed per 1,000 API calls: &euro;2 / $2.25 on the Lifetime License and the Monthly plan
- You set a monthly spend limit. At that limit the API returns `402` with [`SPENDING_LIMIT_REACHED`](/api-reference/error-codes#billing-errors)
- Extra calls appear on your next monthly invoice

When extra calls are off, API calls beyond your allocation return `402` with error code [`CREDITS_EXHAUSTED`](/api-reference/error-codes#billing-errors) until your next month starts.

You can turn extra calls on or off in your [account settings](https://humandesignapi.nl/dashboard/settings).

### Cancellation

When you cancel the Monthly plan:

- Your plan stays active until the end of the current billing period
- At the end of the period, your remaining API calls expire and no new API calls are added
